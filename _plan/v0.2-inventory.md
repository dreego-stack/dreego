# v0.2 render foundation — behavioral inventory (Slice 1)

Status: analysis only, no code changes. Captured 2026-09-01.

## SSRContext classification

Source: core/internal/context/context.go

Render-neutral (work without HTTP):
- Data, Set, Delete, Get — in-memory data map
- Errors, Old — data-map lookups
- RequestID — via context.Context
- FormError, SessionError — error flags only

HTTP-only (dereference c.R / c.W, panic on nil request):
- Param — c.R.PathValue
- Query — c.R.URL.Query
- FormValue — c.R.ParseForm
- SessionVal, SetSessionVal, DelSessionVal, DestroySession — c.R / c.W
- CSRFToken — via SessionVal
- Redirect — http.Redirect(c.W, c.R)

Key finding: NewSSR tolerates a nil request (falls back to context.Background),
but the HTTP-only methods panic on nil. The v0.2 plan forbids this capability
model ("Runtime panics caused by a nil request are not an acceptable capability
model"). HTTP-only operations must fail at generation/build time outside the
SSR target.

## Generated code coupling

Source: internal/transpiler/

- codegen_component.go: components render as dreego.ComponentFunc(func(ctx *dreego.SSRContext) (string, error))
- codegen_page.go: pages have a separate render func (c *dreego.SSRContext) and handler func (w, r)
- codegen_layout.go: layouts render as func(c *dreego.SSRContext, content, head string) (string, error)
- codegen_error.go: error pages render as func(c *dreego.SSRContext) (string, error) plus handler
- codegen_form.go: form handlers are func(app *dreego.App, w http.ResponseWriter, r *http.Request)

The render-vs-handler split already exists in generation. Only handlers need
real HTTP types; renderers only need the context.

## dreegotest coupling

Source: dreegotest/render.go

RenderComponent creates httptest.NewRecorder + httptest.NewRequest and calls
dreego.NewSSR(rec, req) — HTTP crutches for pure rendering. This is the central
coupling Slice 2 must dissolve.

## Public API classification

Source: core/facade.go

Render-neutral: Component, ComponentFunc, App, New, Store types, NewCookieStore,
ValidateForm, Setter, RequestIDFromCtx, ServerConfig, DefaultServerConfig.

HTTP-only: NewSSR(w, r), WithStore(r, s), BindForm(r, target), SaveOld/SaveErrors
(via SSRContext), middleware factories (RequestLogging, MaxBodyReader, Compress,
CSRF, Recovery, RequestID).
