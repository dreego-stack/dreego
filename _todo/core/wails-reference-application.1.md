# Wails reference application

- Area: examples
- Phase: Wails
- Goal: prove the supported desktop workflow in an accessible reference application.
- Acceptance: the application builds without project-owned npm configuration, exercises rendering, navigation, assets, typed bindings, and shutdown, and documents keyboard, focus, screen-reader, development, packaging, and troubleshooting behavior.
- Depends on: wails-bindings-lifecycle.1
